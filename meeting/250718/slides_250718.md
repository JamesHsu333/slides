# Personalized Image Aesthetics Assessment  
## with Rich Attributes (PARA)  
**CVPR 2022 — Paper Summary**  
James Hsu – July 18th 2025

---

## Motivation

- Traditional Image Aesthetic Assessment (IAA) assumes a universal notion of beauty
- Real-world aesthetics are subjective and personalized
- No existing dataset supports fine-grained personalized modeling
- Need for both **objective** and **subjective** annotations to enable personalized learning

---

## PARA Dataset Overview

- **PARA** = *Personalized Aesthetics with Rich Attributes*
- 31,220 images, 438 unique subjects
- Each image rated by ~25 different individuals

---

## Objective Attributes (Image-centric)

Each image is labeled with 9 visual attributes:

- Aesthetics
- Quality
- Composition
- Color
- Depth of Field
- Content
- Light
- object emphasis
- Scene categories

---

## Subjective Attributes (User-centric)

Each user-image pair includes 4 subjective labels:

- Emotion
- Difficulty of judgement
- Content preference
- Willingness to Share

Users also provided anonymized background info:

- Age
- Gender
- Education level  
- Art experience
- Photography experience  
- Personality traits (Big-Five personality traits)

---

## Key Statistical Insights

- Subjective attributes strongly correlate with aesthetic ratings
- Inter-rater disagreement is explainable via user characteristics
- Content preference, emotion, and sharing willingness are major factors for personalized taste

## Conditional PIAA Model

A two-branch neural model:

1. **Image encoder** (e.g., ResNet) extracts image features
2. **User encoder** converts personal attributes into embeddings

These are fused to predict a **personalized aesthetic score**  
(conditioned on user profile)

---

## Model Architecture (Simplified)

```text
+--------------------+     +---------------------+
|   Image Features   |     |   User Attributes   |
|  (ResNet, etc.)    |     |   (Embedding Layer) |
+---------+----------+     +----------+----------+
          |                          |
          v                          v
     Image Branch            User Embedding
          \______________________/       
                  Fusion         
                     |
                     v
        Personalized Aesthetic Score
```
---

## Training Objective

The model is trained to minimize Mean Squared Error (MSE) between predicted and true scores.

Loss Function:

$\mathcal{L}{MSE} = \frac{1}{N} \sum_{i=1}^{N} \left( y_i - \hat{y}_i \right)^2$

Where:
- $y_i$: Ground-truth rating (from user i)
- $\hat{y}_i$: Model prediction for user i
- $N$: Total number of user-image pairs

---

## Experimental Results
- Models trained with user attributes consistently outperform user-agnostic baselines
- Adding even partial user info improves performance
- Incorporating subjective attributes like emotion boosts prediction accuracy
