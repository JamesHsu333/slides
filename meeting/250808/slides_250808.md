# EAT: An Enhancer for Aesthetics-Oriented Transformers
### ACMMM 2023 Summary  
James Hsu – August 8th 2025

---

## Motivation

- Existing Transformer architectures have **not consistently outperformed CNNs** in Image Aesthetic Assessment (IAA) tasks.
- One key reason is the **global, dense self-attention** in Transformers:
  - Tends to **focus heavily on salient foreground regions**.
  - **Ignores subtle aesthetic cues** in background areas.
- This leads to:
  - **High computational cost**  
  - **Slow convergence**
  - **Overfitting** on small-scale IAA datasets

---

## Proposed Method: EAT

- EAT = Enhancer for Aesthetics‑Oriented Transformers
- Introduces a **deformable**, **sparse**, and **data-dependent** attention mechanism.
- Learns **offsets** to dynamically select important positions for aesthetic assessment.
- Enables the model to **fine-tune attention distribution** based on image content.

## Interest Generation Module

- Goal: Generate **differentiable interest points** to replace fixed reference points in deformable transformers.
- Lightweight module $Net_{in}$ maps feature map $F$ into coordinates $(Px, Py)$:

$(Px, Py) = Tanh(Net_{in}(F))$

- Output: $2×H_{in}×W_{in}$ feature map
- Two channels = $horizontal (Px)$ and $vertical (Py)$ coordinates
- Kernel size $k_{in}$ controls the number of interest points
- All coordinates are **normalized to $(-1, +1)$** for training efficiency

---

## Offsets Generation Module

- Computes offset values $(Ox, Oy)$ for each interest point:

$Q = F * W_Q$

$(Ox, Oy) = Tanh(Net_{of}(Q))$

- Ensures **same spatial resolution** as interest map (matched kernel size $k_{of} = k_{in}$)
- Offsets help refine attention location flexibly

---

## Offset Guidance Module

- Designed to **balance attention** between foreground and background
- First: Determine if **offset direction and interest point are in the same quadrant**:

$w = 1 if ReLU(OxPx) * ReLU(OyPy) > 0$

$η otherwise  (0 < η < 1)$

- This **weakens attention drift** toward saliency if not aligned, encouraging background awareness

---

## Offset Random Rotation (Early Training)

- Introduces randomness to **avoid local optima**:
- Randomly rotate offsets during early training epochs:

$(Ox̄, Oȳ) = [w(Ox·cosα − Oy·sinα), w(Oy·cosα + Ox·sinα)]$

$α = (1 - e/E) · Random(-π, π)$

- Enables **exploration of aesthetic cues** in background early on, stabilizes over time

---

## Feature Sampling and Attention

- Final sampling coordinates:

$(Px + Ox̄, Py + Oȳ)$

- Use **bilinear interpolation** to sample features:

F$̄ = B[F, Tanh(P + Ō)]$

- Project sampled features:

$K = F̄ * W_K$
$V = F̄ * W_V$

- Use standard multi-head attention on Q, K, V to compute final output

---

## Overall EAT Architecture

- **Stage 1–2**: Swin Transformer blocks with shift window attention (local focus)
- **Stage 3–4**: EAT-enhanced blocks (global modeling between foreground and background)
- **Output head**: Predicts final aesthetic score

> The architecture gradually shifts from **local aggregation** to **global relational modeling**

---

## Design Rationale

- Avoid using EAT in early stages:
- May lead to **information loss** if applied before meaningful features emerge
- EAT blocks later in network:
  - Emphasize **foreground-background relations**
  - Preserve **background aesthetics** alongside salient features
