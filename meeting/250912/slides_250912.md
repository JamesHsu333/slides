# ELTA: An Enhancer against Long-Tail for Aesthetics-oriented Models
## ICML 2024 – Summary
James Hsu – Sep 12th 2025

---

# Problem

- **Image Aesthetics Assessment (IAA)** datasets are **long-tailed**  
  - Most images → medium scores  
  - Few images → very low / very high scores  
- Consequences:
  - Models biased to majority
  - Poor prediction for minority samples
  - Fairness and generalization compromised

---

# Challenges in IAA

1. **No clear class boundaries**  
   - Scores are continuous, subjective  

2. **Feature–label mismatch**  
   - Same image can have different opinions  
   - Raw-pixel augmentations may break aesthetics

<img class="w-50" src="./images/250912/distribution.png"></img>

3. **Smooth output distributions**  
   - Hard to select reliable pseudo-labels  

---

# ELTA Overview

**Three plug-and-play modules:**

1. **TFA** – Tail Features Augmentation  
2. **FLSA** – Feature-Label Similarity Alignment  
3. **APDS** – Adaptive Probability Distribution Sharpening  

---

# Problem Setup

- Two tasks in **Image Aesthetics Assessment (IAA):**

### 1) Distribution Prediction
- Training set: $D = \{(x_i, y_i)\}_{i=1}^N$
- $x_i$: input image  
- $y_i = [y_i^1, y_i^2, \dots, y_i^C]$: empirical PMF of human ratings  
- Goal: predict $\hat{y}_i$ close to $y_i$  
- Mean Opinion Score (MOS):
  - Ground-truth: $s_i = \sum_{j=1}^C j \cdot y_i^j$  
  - Predicted: $\hat{s}_i = \sum_{j=1}^C j \cdot \hat{y}_i^j$

### 2) Score Regression
- Each image has scalar score $y_i$  
- Model may still output distribution, then compute predicted score $\hat{s}_i$  
- Loss minimized between $\hat{s}_i$ and $s_i$

---

# Long-Tail Challenge

- IAA datasets → **long-tailed distributions**
  - Most images cluster around the mean $\bar{s}$
  - Minority = very low or very high scores

- Consequence:
  - Model tends to predict medium scores
  - Error grows for minority:
  $|\hat{s}_i - s_i| \propto |s_i - \bar{s}|$

Core focus: **reduce amplified errors on minority samples**

---

# Tail Features Augmentation (TFA)

- **Why feature-level?**
  - Pixel-level augmentation (crop, flip, rotate) may ruin aesthetics
  - Feature-level mixup preserves aesthetics while generating diverse samples

<img class="w-60" src="./images/250912/TFA.png"></img>

---

# Mixup Formulation

Given two samples $(x_i, y_i)$, $(x_j, y_j)$:

- Extract features at layer $k$:  
  $z_i^k = f^k(x_i), \; z_j^k = f^k(x_j)$

- Mixup:
  
  $\tilde{z}^k = \lambda z_i^k + (1-\lambda)z_j^k$

  $\tilde{y} = \lambda y_i + (1-\lambda) y_j$

- When $k=0$: equivalent to pixel-level mixup

---

# Sampling Strategy

- **Problem**: Random sampling → dominated by majority → little benefit to minority  
- **Solution**: Two-stage sampling  

### Stage 1: Choose first sample $z_i$

$P(i) = \frac{\exp(|\bar{s} - s_i|/\tau_1)}{\sum_{k=1}^B \exp(|\bar{s} - s_k|/\tau_1)}$

- Farther from mean → higher probability  
- Bias toward minority  

---

# Sampling Strategy (cont.)

### Stage 2: Choose pair $z_j$

$P(j|i) = \frac{\exp(\tau_2 / |s_i - s_j|)}{\sum_{k \neq i} \exp(\tau_2 / |s_i - s_k|)}$

- Smaller score difference → higher probability  
- Ensures aesthetics consistency in pairs  

---

# Improved Mixup Coefficient

Traditional mixup: $\lambda$ from Beta distribution  

ELTA redefines:

$\lambda = \frac{P(i)}{P(i) + P(j)} = \frac{\exp(|\bar{s}-s_i|/\tau_1)}{\exp(|\bar{s}-s_i|/\tau_1) + \exp(|\bar{s}-s_j|/\tau_1)}$


Sample closer to minority gets **higher weight**  
- Mixed feature dominated by minority  
- Reduces accidental dominance of majority  

---

# Feature-Label Similarity Alignment (FLSA)

- **Motivation**:  
  - IAA features often confused → mismatch with labels  
  - Principle: “Closer in label space → closer in feature space”

<img class="w-80" src="./images/250912/FLSA.png"></img>

---

# FLSA Formulation

1. **Feature similarity matrix**

$M^f_{i,j} = \cos(z_i, z_j) = \frac{z_i \cdot z_j}{|z_i||z_j|}$


2. **Label similarity matrix**

$M^l_{i,j} = 1 - \frac{|s_i - s_j|}{\max_k s_k - \min_k s_k}$


- $M^l_{i,j}=1$: identical scores  
- $M^l_{i,j}=0$: largest score gap  

---

# FLSA Loss

- Alignment loss:

$\mathcal{L}_{align} = \text{MSE}(M^f, M^l)$


- Added as regularization:

$\mathcal{L} = \mathcal{L}_{sup} + \alpha \cdot \mathcal{L}_{align}$


Forces feature space to follow label similarity → better representation  

---

# Adaptive Probability Distribution Sharpening (APDS)

- **Problem**: IAA predictions too smooth  
  - Hard to set threshold for pseudo-label selection  

- **Goal**: Sharpen minority predictions → more likely to pass threshold

<img class="w-120" src="./images/250912/APDS.png"></img>

---

# Temperature Scaling

- Given logits $z_i$:

$\hat{y}_i = \text{Softmax}(z_i/\tau)$


- $\tau > 1$: smoother  
- $\tau < 1$: sharper  

---

# Adaptive Temperature

Define sample-specific temperature:

$\tau_i(\beta) = e^{-\beta |\hat{s}_i - \bar{s}|}$


- Minority (far from mean) → $\tau_i \to 0$ → sharper  
- Majority (close to mean) → smoother  

---

# Pseudo-label Selection

- Keep samples if:

$\max(\hat{y}_i(\beta)) \ge t$

- **Grid search** finds best $(\beta^*, t^*)$ by minimizing MAE:

$(\beta^*, t^*) = \arg\min_{\beta,t} \sum | \hat{s}_i(\beta,t) - s_i |$

Ensures high-quality pseudo-labels  

---

# Overall Architecture

- **Backbone**: Swin Transformer V2  
- **Modules**: TFA, FLSA, APDS (independent, plug-and-play)  

Flow:
1. Input → Swin Transformer features  
2. TFA augments minority features  
3. FLSA aligns features with labels  
4. APDS sharpens predictions → pseudo-labels  
5. Combine labeled + pseudo-labeled data for training

# Training Loss

1. **Labeled Loss (Ls)**  

$L_s = \frac{1}{B_l} \sum H(y_i^l, f(x_i^l))$
- EMD for distribution labels (e.g. AVA)  
- MSE for scalar labels  

---

# Training Loss (cont.)

2. **Unlabeled Loss (Lu)**  

$L_u = \frac{1}{B_u} \sum \mathbf{1}[\max(\hat{y}_i^u(\beta^*)) \ge t^*] \cdot H(\hat{y}_i^u, f(x_i^u))$

- Only high-confidence pseudo-labels are used  

3. **Final Loss**

$L = L_s + L_u$

---

# Summary

- **TFA**: Feature-level mixup → generate strong minority features  
- **FLSA**: Align feature similarity with label similarity → reduce mismatch  
- **APDS**: Adaptive sharpening → reliable pseudo-labels  
- **Training**: Labeled + pseudo-labeled loss → enhance performance on long-tail  

---

# Module Comparison

| Module | Problem | Method | Effect |
|--------|---------|--------|--------|
| **TFA** | Minority under-represented | Feature-level mixup, biased sampling | Enhance minority features |
| **FLSA** | Feature-label mismatch | Align cosine similarity (features vs labels) | Consistent representation |
| **APDS** | Smooth predictions | Adaptive temperature scaling | High-quality pseudo-labels |
